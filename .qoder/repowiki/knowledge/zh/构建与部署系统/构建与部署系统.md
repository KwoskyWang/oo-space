该项目采用 **Vite + React + TypeScript** 作为前端构建体系，配合 Python 本地服务器提供图像生成能力，并通过 GitHub Actions 实现自动化部署。整体构建流程如下：

### 构建系统
- **包管理与脚本**：`package.json` 定义了三个核心脚本：`dev`（启动 Vite 开发服务器）、`build`（先执行 `tsc -b` 类型检查再调用 `vite build` 打包）、`preview`（预览构建产物）。
- **构建工具链**：使用 Vite 6.3.5 作为构建器，`@vitejs/plugin-react` 插件支持 React JSX/TSX；TypeScript 5.8.3 通过 `tsconfig.app.json`、`tsconfig.node.json` 分别配置应用与 Node 端编译选项。
- **Vite 配置极简**：`vite.config.ts` 仅启用 React 插件，无额外优化配置，输出目录为默认的 `dist/`。

### 后端服务与图像生成
- **Python 本地服务器**：`server.py` 基于标准库 `http.server.ThreadingHTTPServer` 实现轻量 Web 服务，监听 `127.0.0.1:8765`，提供静态文件服务、`/api/config` 配置接口和 `/api/generate` 图像生成接口。
- **图像生成管线**：服务端通过 `subprocess` 调用 `scripts/image_gen.py` 执行 OpenAI GPT Image 模型的生成或编辑任务，上传文件存入 `uploads/`，输出结果写入 `output/imagegen/`。
- **配置文件**：`config.json`（示例见 `config.example.json`）管理 API Key、模型名、质量、尺寸等参数，支持环境变量覆盖。

### 资源处理脚本
- `scripts/crop-oo-grid.mjs`：PNG 精灵图裁剪工具。
- `scripts/open_app.command`：macOS 本地应用启动脚本。

### 部署流程
- **CI/CD**：`.github/workflows/deploy.yml` 在推送到 `main` 分支时触发，步骤包括：检出代码 → 安装 Node.js 20 → `npm ci` 安装依赖 → `npm run build` 构建 → SSH 密钥配置 → 通过 `rsync` 将 `dist/` 同步到远程服务器 `/var/www/oo-space/`。
- **本地快速推送**：`deply.sh` 封装了 git add/commit/push 的快捷命令（注意文件名拼写为 deply.sh）。

### 约定与约束
- 构建产物统一输出到 `dist/` 目录，由 CI 直接部署。
- 前端私有项目（`"private": true`），不发布到 npm。
- 开发环境通过 `--host 127.0.0.1` 限制访问地址。
- 图像生成超时设为 600 秒，失败返回详细 stderr 信息。
- 上传文件名经安全清洗，仅允许 png/jpg/jpeg/webp 格式。
