根目录作为单一可部署单元：`server.py` 启动后同时承担三件事——(1) 通过 `/api/config` 暴露 OpenAI 配置供前端读取；(2) 通过 `POST /api/generate` 接收 multipart 表单（prompt/history/图片），用 subprocess 调用 `scripts/image_gen.py` 执行 generate/edit 模式，结果写入 `output/imagegen/`；(3) 通过 `/images/` 和根路径静态托管 `public/` 下的 Vite 构建产物。前端（frontend_app）在开发时由 `npm run dev` 独立运行 Vite 热更新，生产环境则与后端同进程部署，无需反向代理。`config.json`（示例见 `config.example.json`）被 server 与 image_gen 脚本共同读取，键值优先取 JSON 再回退环境变量。`deply.sh` 封装 npm build 与打包流程，实现一键发布。
