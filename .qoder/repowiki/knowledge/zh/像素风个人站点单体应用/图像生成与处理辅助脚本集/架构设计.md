本模块由四个相互独立的脚本组成，无共享代码与依赖方向：
- `image_gen.py`：基于 argparse 子命令的 Python CLI，封装 OpenAI `images.generate` 与 `images.edit` 两个端点，支持单条调用与 JSONL 批量异步并发（asyncio.Semaphore），内置指数退避重试、速率限制检测、Pillow 可选下采样及透明背景校验。
- `crop-oo-grid.mjs`：纯 Node.js ESM 脚本，直接解析 PNG 二进制（校验签名、IHDR/IDAT/IEND 分块、Paeth 预测解码），将 1024×1024 RGBA 网格切分为 3×3 的 pose 精灵图并输出 JSON 元数据。
- `convert-to-webp.mjs`：使用 sharp 库递归扫描 `public/assets/` 下的 PNG 文件并批量转换为 WebP，输出到同级 webp 子目录。
- `open_app.command`：macOS zsh 启动器，检查 Python 3 与 openai>=2.0.0，自动 pip 安装依赖后以子进程方式运行 `server.py` 并在端口 8765 打开浏览器。
各脚本仅依赖标准库或第三方 SDK，彼此之间完全解耦。
