- Hook 返回值统一以对象形式暴露状态与方法，便于解构使用（如 `{ isVisible, handleClick }`、`{ season, setSeason, toggleSeason }`）。
- 对浏览器 API 的访问均包裹 `typeof window === 'undefined'` 守卫，确保服务端渲染安全。
- 异步清理逻辑通过返回 cleanup 函数或全局变量管理（如 `activeCleanup`、`hideTimer`/`resetTimer` ref），并在组件卸载或特效结束时显式释放。
- 可选配置通过具名 options 对象传入，并提供合理的默认值与 fallback（如 `season` 默认为 summer、`containerSelector` 回退到 `document.body`）。
