该模块为纯静态资源目录，由后端服务器直接托管，无构建流程。
- `index.html` 是应用入口，通过 `<link>` 引入 `styles.css`，通过 `<script src="/app.js">` 加载交互逻辑。
- `app.js` 使用原生 DOM API（querySelector、FormData、fetch）实现聊天式图片生成界面：维护 `chatHistory` 数组，向 `/api/config` 拉取配置，向 `/api/generate` 提交 prompt/size/quality/images 等表单数据，并动态渲染结果气泡与下载链接。
- `dragon-effect-demo.html` 是独立演示页，通过 ES module 从 `/src/effects/dragonEffect.ts` 导入 `initDragonEffect`，以 `assetBasePath: "/assets/dragon"` 加载精灵图，用于验证小龙星效动画。
- `assets/` 下按主题分目录存放 PNG 精灵图：`dragon/`（含 `stars/` 子目录粒子帧）、`oo-poses/`、`oo-poses-7/`、`oo-winter-poses/` 以及单张角色图 `oo-pixel-girl.png`，命名采用序号前缀便于按序播放。
- 依赖方向单向：HTML → CSS + JS → 后端 `/api/*` 接口；演示页额外依赖 `/src/effects/dragonEffect.ts`。
