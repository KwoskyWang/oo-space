本模块为纯展示型 React 组件目录，按职责划分为三层：
- 基础原子层（PixelPrimitives.tsx）：定义 PixelButton、PixelCard、PixelLinkButton、PixelPanel、PixelSectionHeading、PixelTag 等无状态 UI 基元，通过 `as` prop 支持语义化标签渲染。
- 业务区块层（HeroSection、WorksSection、AboutSection、Footer、MemoryGallery 等）：组合原子组件与数据模型（siteContent、poseMap、seasonContent），负责页面级布局与内容编排。
- 交互与特效层（SeasonToggle、SeasonalDecorLayer、ScrollSparkleTrail、TechParticleLayer、MarqueeText、FloatingFruits 等）：封装动画、粒子、季节切换等视觉行为。
依赖方向单向向下：业务区块 → 原子组件/子组件 → 外部 data 类型（../data/*），组件之间仅通过 props 通信，无全局状态或副作用。OoPixelAvatar 作为跨层级共享的角色渲染核心，被 MemoryCard、HeroSection、WorkCard 等多处复用。
