根目录作为统一入口，通过 `server.py`（Python ThreadingHTTPServer）对外暴露 HTTP API：`GET /api/config` 返回 OpenAI 配置，`POST /api/generate` 接收 multipart 表单（prompt/history/图片），调用 `scripts/image_gen.py` 执行图像生成或编辑，结果写入 `output/imagegen/` 并通过 `/images/` 路径供前端访问；静态资源来自 `public/` 目录，由 Vite 构建产物构成。前端（frontend_app）通过 Vite 开发服务器独立运行，生产环境则由 `server.py` 同时托管静态文件与后端 API，形成前后端同进程部署。`config.json`（示例见 `config.example.json`）集中管理 OPENAI_API_KEY、BASE_URL、MODEL、QUALITY、SIZE 等参数，被 server 和 image_gen 脚本共同读取。`deply.sh` 提供一键打包发布流程。
