模块按职责分为两层：
- `src/hooks/`：纯 React Hook 实现，无副作用 DOM 操作。`useEasterEggClick` 通过内部 `ref` 计数与 `setTimeout` 实现连续点击触发；`useSeasonTheme` 将季节状态同步到 `document.documentElement.dataset.season` 并持久化到 `localStorage`。
- `src/effects/`：独立于 React 的函数式特效库。`dragonEffect.ts` 暴露 `showDragonEffect`（直接操作 DOM + Canvas 绘制粒子）和 `initDragonEffect`（事件委托绑定），通过全局 `activeCleanup` 保证同一时刻仅有一个特效实例运行，并通过 `imageCache` Map 缓存已加载图片避免重复请求。
依赖方向单向：hooks 可引用 effects 提供的类型或数据，effects 不依赖 hooks，保持可被任意框架复用。
