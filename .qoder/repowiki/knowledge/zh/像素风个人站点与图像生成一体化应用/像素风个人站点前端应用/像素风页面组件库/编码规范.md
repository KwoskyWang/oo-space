- 组件统一以函数式声明导出默认或具名导出，props 通过独立的 `type XxxProps = {...}` 接口定义并解构使用。
- UI 原子组件通过 `as` prop 支持多标签渲染（如 PixelCard as="article|div"），保持语义灵活性。
- CSS 类名采用 BEM 命名规范，修饰符通过模板字符串动态拼接（如 `memory-card--${memory.placeholderTheme}`）。
- 所有可交互元素均设置 aria-label / aria-hidden 等无障碍属性，图标使用 emoji 并通过 aria-hidden 隐藏装饰性字符。
- 组件间通过 props 传递 poseMap、season、content 等共享上下文，避免引入全局状态或 hooks 管理跨组件状态。
- 像素角色统一通过 OoPixelAvatar 组件渲染，传入 pose、size（mini/card/section/footer）和可选 decorative 属性控制显示。
