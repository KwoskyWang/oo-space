- 所有设计令牌统一以 `--` 前缀的 CSS 自定义属性形式在 `:root` 或 `html[data-season]` 中声明，组件样式只引用变量不硬编码颜色值。
- 像素风格通过固定边框宽度（`--pixel-border-width`）、偏移阴影（`box-shadow: Xpx Ypx 0 color`）和 `steps()` 缓动函数实现，避免模糊效果。
- 组件类名遵循 BEM 命名（如 `.pixel-nav__brand`、`.memory-card__sticker`），并使用 `::before` / `::after` 伪元素叠加装饰层。
- 响应式通过 `@media (max-width: 980px)` 和 `720px` 两个断点统一覆盖，移动端优先调整字号、间距与布局网格。
- 动画统一使用 `steps(n, end)` 模拟像素帧动画，并在 `@media (prefers-reduced-motion: reduce)` 中禁用或缩短过渡。
- 主题切换通过 `html[data-season="winter"]` 属性选择器覆盖变量与特定类样式，保持默认夏季主题不变。
