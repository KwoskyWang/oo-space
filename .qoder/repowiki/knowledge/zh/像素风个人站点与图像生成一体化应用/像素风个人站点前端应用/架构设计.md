应用以 App.tsx 为根入口，main.tsx 挂载到 index.html；各子模块按职责分层协作：components 提供页面区块与 UI 元素，hooks_and_effects 暴露 useSeasonTheme/useEasterEggClick 等 Hook 及 dragonEffect Canvas 特效，data_content 集中管理 siteContent/seasonContent/poseMap 等静态数据，styles_themes 通过 CSS 变量与 tokens.css 驱动像素主题与季节配色，static_assets 提供运行时所需的图片与演示页。组件通过 import 引用 Hook 与数据，样式文件按页面模块拆分并在 global.css 中统一引入，形成「组件 → Hook/数据 → 样式」的单向依赖链。
