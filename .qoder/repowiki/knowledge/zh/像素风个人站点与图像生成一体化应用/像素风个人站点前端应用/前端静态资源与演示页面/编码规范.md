- HTML 使用语义化标签（`<main>`、`<section>`、`<article>`、`<header>`）配合 `aria-label` / `aria-live` 提升可访问性。
- CSS 通过 `:root` 定义设计令牌（颜色、阴影、字号），组件样式统一使用 BEM 风格类名（如 `.message.user .bubble`、`.dragon-effect__dragon`）。
- JS 通过 `document.querySelector` 获取元素后以函数形式组织行为（`addMessage`、`renderThumbs`、`resultNode`），避免全局污染。
- 精灵图命名遵循 `序号_描述.png` 的有序前缀约定，便于按序帧播放动画。
