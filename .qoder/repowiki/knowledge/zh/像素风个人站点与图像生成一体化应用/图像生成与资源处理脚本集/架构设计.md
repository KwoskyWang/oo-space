本模块由三个相互独立的脚本组成，无共享代码：
- `crop-oo-grid.mjs`：纯 Node.js 脚本，直接解析 PNG 二进制（校验签名、IHDR/IDAT/IEND 分块、Paeth 预测解码），将 1024×1024 RGBA 网格切分为 3×3 的 pose 精灵图并输出 JSON 元数据。
- `image_gen.py`：基于 argparse 的 Python CLI，封装 OpenAI `images.generate` 与 `images.edit` 两个端点，支持单条与 JSONL 批量异步并发（asyncio.Semaphore）调用，内置重试退避、速率限制检测、Pillow 可选下采样及透明背景校验。
- `open_app.command`：macOS zsh 启动器，检查 Python 3 与 openai>=2.0.0，自动 pip 安装依赖后以子进程方式运行 `server.py` 并在端口 8765 打开浏览器。
依赖方向单向：脚本仅依赖标准库或第三方 SDK（node:fs/node:path/node:zlib、openai、Pillow），彼此之间无耦合。
