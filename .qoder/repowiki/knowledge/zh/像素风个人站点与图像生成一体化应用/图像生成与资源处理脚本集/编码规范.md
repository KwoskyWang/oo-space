- CLI 参数统一通过 argparse 子命令组织，共享参数由 `_add_shared_args` 函数集中注册，各子命令再追加专属参数。
- 错误处理使用 `_die(message, code)` 统一向 stderr 输出并以 SystemExit 退出，警告使用 `_warn` 而非抛出异常。
- 可选依赖（如 Pillow、openai SDK）采用运行时 try/except 导入失败时给出带安装提示的友好错误信息，避免启动即崩溃。
- API 调用封装为异步函数并内置指数退避重试，通过 `_is_transient_error` 和 `_extract_retry_after_seconds` 识别 429/超时等可恢复错误。
- 输出路径生成遵循命名约定：单文件直接使用 `--out`，多结果按 `image_{i}.ext` 或 `{stem}-{i}{ext}` 编号，批量模式强制要求 `--out-dir`。
